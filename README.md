# WadiGuard

نموذج عربي تفاعلي لمراقبة الأودية والإنذار المبكر، يحاكي انتقال المياه بين أربع محطات مع خريطة ورسوم وتنبيهات.

## التشغيل محليًا

يتطلب Node.js 22 أو أحدث، دون تثبيت مكتبات.

```sh
npm start
```

افتح http://localhost:3000. للاختبار: `npm test`. لبناء الموقع: `npm run build`.

## رابط المشروع على GitHub Pages

1. ارفع محتويات الحزمة بعد فك الضغط إلى جذر مستودع GitHub على فرع `main`، بما فيها مجلد `.github`.
2. من **Settings → Pages → Source** اختر **GitHub Actions**.
3. من **Actions** شغّل **Test and publish WadiGuard → Run workflow** إذا لم يبدأ النشر تلقائيًا.
4. بعد نجاح النشر يظهر رابط الموقع في **Settings → Pages** ونتيجة عملية النشر.

الإعداد جاهز؛ الرابط العام لا يُنشأ إلا بعد رفع الملفات ونجاح النشر. [تعليمات GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

## التجربة

اختر اتجاه المياه وسرعتها من مختبر المحاكاة ثم اضغط «إطلاق الموجة». الأخضر طبيعي، والبرتقالي تحذير أو تنبيه مبكر، والأحمر خطر. يمكن إيقاف المحاكاة وتغيير سرعة العرض وتصدير القراءات.

جميع البيانات محاكاة تعليمية؛ لا يوجد اتصال فعلي بحساسات أو LoRa، والنموذج غير مخصص للإنذار الميداني.
